## The emoji

🏝️ — a desert island.

One glyph, one postcard. A plane only promises the journey; an island
*is* the destination. Palm tree, sand, and turquoise sea packed into a
single image — it lands at a glance as "escape to paradise", the exact
feeling a stranger needs to want to book the trip. It is the dream
itself, not the transport to get there.

## How it works

`main.py` (Python standard library only, no network, fully deterministic)
writes exactly that one emoji — and nothing else — to
`/output/entry.txt`: no trailing newline, no extra whitespace. The
emoji is U+1F3DD (desert island) plus U+FE0F (variation selector), so
it renders as a colour emoji everywhere. Two code points, inside the
bounty's 1–8 character gate.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
